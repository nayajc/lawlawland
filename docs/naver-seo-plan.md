## 1순위 — 네이버 생태계 진입 (효과 최대, 사용자 직접 수행)

### A. 네이버 서치어드바이저 (필수, 30분)
- https://searchadvisor.naver.com → 사이트 등록 `https://ohsoojin.com`
- 소유확인: 이미 메타태그 인증코드 박혀 있음 → "HTML 태그" 방식 선택 후 확인
- 요청 > **사이트맵 제출**: `https://ohsoojin.com/sitemap.xml`
- 요청 > **RSS 제출**: `https://ohsoojin.com/feed`
- 수집/색인 현황, 검색 노출 키워드를 주기적으로 모니터링

### B. 네이버 블로그 개설 (가장 중요한 통로)
- 오수진 변호사 명의 네이버 블로그 개설
- 사이트 블로그 글을 **요약·재구성**해 네이버 블로그에도 발행 (주 2~3회)
- 본문 하단에 ohsoojin.com 상담 링크 + 프로필 위젯
- 블로그명/별명/소개에 "이혼전문변호사" 키워드 포함

### C. 네이버 스마트플레이스 (지역 검색 노출)
- "법무법인 큐브 서울사무소" 또는 변호사 사무소로 등록
- "강남 이혼변호사", "서울 이혼변호사" 검색 시 지도/플레이스 노출
- 방문자 리뷰가 쌓이면 순위 상승 → 상담 고객에게 리뷰 요청

### D. 지식iN 전문가 답변
- 이혼/재산분할/양육비 질문에 변호사로 답변
- 답변 하단 프로필 → 신뢰도 + 사이트 유입

## 2순위 — 키워드·콘텐츠 전략

### 네이버 검색 의도형 키워드 (제목·H1에 그대로)
사람들이 실제로 치는 말 그대로 쓴다. (정보성/긴 꼬리 키워드가 진입 쉬움)

| 카테고리 | 타겟 키워드 (블로그 글 제목 예시) |
|---|---|
| 재산분할 | "이혼 재산분할 기준 총정리", "전업주부 재산분할 비율", "혼인 전 재산 분할되나요" |
| 위자료 | "이혼 위자료 얼마나", "상간남/상간녀 위자료 소송 절차", "위자료 청구 기간" |
| 양육 | "양육비 산정기준표 보는 법", "양육비 안 줄 때 강제집행", "면접교섭권이란" |
| 절차 | "협의이혼 절차와 기간", "재판상 이혼 사유 6가지", "이혼소송 비용" |
| 상황별 | "외도 이혼 증거 수집", "가정폭력 이혼", "졸혼 vs 이혼" |

### 글쓰기 원칙
- 제목 = 검색어 그대로, 첫 문단에 핵심 답 먼저
- 1,500자 이상, 소제목(H2/H3) 구조, 표/리스트 활용
- 내부 링크: 관련 글 + 계산기/상담 페이지로 연결
- 발행 주기 일정하게 (네이버는 꾸준함을 신뢰 신호로 봄)

## 향후 사이트 코드 개선 후보 (선택)
- 각 정적 페이지(about/cases/guide/calculator)에 페이지별 키워드 메타 점검
- `FAQPage` JSON-LD를 가이드/계산기 페이지에 추가 → 네이버/구글 리치결과
- 블로그 글에 본문 내 관련 글 자동 추천(내부링크) 섹션
- 카테고리/태그 아카이브 페이지 색인 + 사이트맵 포함
